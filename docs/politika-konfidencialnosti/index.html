Политика конфиденциальности

Сайт не хранит персональные данные на сервере. Когда вы заполняете форму заявки, данные (имя, телефон, тип бизнеса, страница сайта) передаются в WhatsApp в виде сообщения, которое вы отправляете сами.

Сайт может использовать Яндекс Метрику и Google Analytics, чтобы понимать, какие страницы полезны посетителям. Эти сервисы получают обезличенные данные о посещениях.

Мы используем полученные данные только для связи с вами, подготовки расчёта и заключения договора. Мы не передаём данные третьим лицам, кроме случаев, предусмотренных законодательством Республики Казахстан.
