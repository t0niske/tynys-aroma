# Tynys — ароматизация бизнеса по подписке

Основной продающий сайт: светлый, понятный, с ценой на первом экране. Мягкие «ароматные» облака, витрина диффузора с живым LED-экраном, тарифы, калькулятор площади, отрасли и каталог.

**Сайт:** https://t0niske.github.io/tynys-aroma/

## Что на странице
- Первый экран с предложением «3 дня бесплатно» и витриной Nova с выносками
- Факты 70% / 94% / 75% и LED-табло
- Как это работает (4 шага), устройства и характеристики
- Тарифы с переключателем Nova 300 / Nova 1000 (1, 3, 6 месяцев)
- Калькулятор: подбирает самый выгодный набор аппаратов под площадь
- Отрасли с рекомендованным аппаратом и ароматами, каталог 32 ароматов
- OdorOut™, цифры, FAQ, заявка в WhatsApp

## Как менять данные
Всё в `js/data.js`: цены, ароматы, отрасли, контакты, FAQ.

## Структура
`index.html` · `css/style.css` · `js/data.js` · `js/led.js` (точечный LED-дисплей) · `js/main.js`.
